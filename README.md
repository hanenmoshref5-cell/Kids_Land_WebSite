# Kids Land 🧸
مشروع لمادة الويب1 في جامعتي وهو بناء موقع ويب كامل من الصفر للنهاية مع فرونت وبباك كامل وربط بينهما 
المشروع عبارة عن:
موقع ويب متكامل لمحل مستلزمات أطفال باسم **Kids Land**، لبيع كل الأشياء اللي ممكن يحتاجها الطفل: عربايات، كراسي طعام، ملابس، ألعاب، سكوترات، باركات (مرابع ألعاب) وغيرها.

## نظرة عامة

يضم الموقع واجهتين رئيسيتين:

- **واجهة المستخدم العادي**: تصفح المنتجات والتسوق من الموقع.
- **واجهة الأدمن (صاحب المتجر)**: إضافة، تعديل، وإخفاء المنتجات بالموقع.

## الصفحات

| الصفحة | الوظيفة |
|---|---|
| Home Page | الصفحة الرئيسية للموقع |
| Sign Up | تسجيل حساب جديد |
| Log In | تسجيل الدخول |
| Products Page | عرض وتصفح المنتجات |
| Admin Page | لوحة تحكم الأدمن لإدارة المنتجات |

## التقنيات المستخدمة

- HTML, CSS, JavaScript
- PHP
- MySQL
- phpMyAdmin

## قاعدة البيانات والتصميم

تم بناء جداول قاعدة بيانات (`kids-land-data.sql`) شاملة لكل البيانات المطلوبة مع تعامل سلس معها، إلى جانب تصميم واجهات أنيقة ومناسبة لفكرة الموقع.
